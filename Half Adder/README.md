# Half Adder

## Overview

A Half Adder is a combinational logic circuit that adds two single-bit binary inputs and produces two outputs: **Sum** and **Carry**. It is one of the fundamental building blocks used in digital arithmetic circuits.

## Objective

- Design a Half Adder using Verilog HDL.
- Verify its functionality through Behavioral Simulation.
- Generate and analyze the RTL Schematic using Vivado.

## Theory

A Half Adder performs the addition of two 1-bit binary numbers.

- **Sum** is obtained using an XOR gate.
- **Carry** is obtained using an AND gate.

### Boolean Expressions

```text
Sum   = A ⊕ B
Carry = A · B
```
